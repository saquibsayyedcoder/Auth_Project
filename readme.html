# 📚 Book Store App A full-stack **Book Store Application** built with **React, Node.js, Express, and MongoDB**. Users can browse books, view details, and authenticated users can add, edit, and delete books. The project focuses on clean UI, responsive design, and real-world CRUD functionality. --- ## 🚀 Features ### 👤 Authentication * User Login & Registration * JWT-based authentication * Protected routes for authorized users ### 📖 Books * View all books * View single book details * Add new books (authenticated users) * Edit book details * Delete books * Upload book images ### 🎨 UI / UX * Modern responsive UI (Tailwind CSS) * Mobile-friendly design * Hover effects & animations * Image previews on upload * Loading & empty states --- ## 🛠️ Tech Stack ### Frontend * React * React Router DOM * Axios * Tailwind CSS ### Backend * Node.js * Express.js * MongoDB * Mongoose * JWT Authentication * Multer (for image upload) --- ## 📂 Project Structure ``` book-store-app/ │ ├── client/ # React Frontend │ ├── src/ │ │ ├── components/ │ │ ├── pages/ │ │ ├── api/ │ │ └── App.jsx │ ├── server/ # Node Backend │ ├── routes/ │ ├── controllers/ │ ├── models/ │ ├── middleware/ │ └── server.js │ └── README.md ``` --- ## ⚙️ Installation & Setup ### 1️⃣ Clone the repository ```bash git clone https://github.com/your-username/book-store-app.git cd book-store-app ``` --- ### 2️⃣ Backend Setup ```bash cd server npm install ``` Create a `.env` file: ```env PORT=5000 MONGO_URI=your_mongodb_connection_string JWT_SECRET=your_secret_key ``` Run backend server: ```bash npm start ``` Server runs on: **[http://localhost:5000](http://localhost:5000)** --- ### 3️⃣ Frontend Setup ```bash cd client npm install npm run dev ``` Frontend runs on: **[http://localhost:5173](http://localhost:5173)** --- ## 🔐 Protected Routes * `/add-book` * `/edit-book/:id` * `/single-book/:id` These routes require authentication. --- ## 📸 Screenshots (Optional) *Add screenshots of Home page, Add Book page, Single Book page here.* --- ##
